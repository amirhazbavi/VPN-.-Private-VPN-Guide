راهنمای جامع و گام‌به‌گام ساخت فیلترشکن خصوصی (رایگان + فروش)

این راهنما صرفاً آموزشی است. مسئولیت استفاده قانونی و رعایت قوانین محل خود با شماست.

۱) پیش‌نیازهای مشترک

  • یک دستگاه کلاینت: ویندوز، مک، اندروید یا iOS.
  • یک برنامه کلاینت: WireGuard، v2rayNG، Nekoray یا sing-box.
  • برای روش‌های سروری: یک VPS با دسترسی root یا sudo.

۲) روش‌های کاملاً رایگان

روش ۲.۱: Cloudflare Workers (VLESS over WebSocket)

  1. حساب رایگان Cloudflare بسازید.
  2. از بخش Workers & Pages یک Worker جدید ایجاد کنید.
  3. کد پروژه‌هایی مثل Cloudflare-VLESS یا edgetunnel را از گیت‌هاب در Worker قرار دهید.
  4. متغیرهای محیطی مثل UUID و HOST را تنظیم کنید.
  5. پس از Deploy، لینک VLESS یا QR Code را در v2rayNG یا sing-box وارد کنید.

روش ۲.۲: Oracle Cloud Always Free

  1. در Oracle Cloud Free Tier ثبت‌نام کنید.
  2. یک Instance با Ubuntu 22.04/24.04 بسازید.
  3. پورت‌های لازم مثل UDP 51820 یا TCP 443 را در Security List باز کنید.
  4. با SSH وصل شوید و یکی از روش‌های بخش ۳ را اجرا کنید.

Complete Step-by-Step Guide to Building a Private VPN (Free + Commercial)

This guide is for educational purposes. You are responsible for using it legally and complying with local laws.

1) Common Prerequisites

  • A client device: Windows, Mac, Android, or iOS.
  • A client app: WireGuard, v2rayNG, Nekoray, or sing-box.
  • For server methods: a VPS with root or sudo access.

2) Completely Free Methods

2.1 Cloudflare Workers (VLESS over WebSocket)

  1. Create a free Cloudflare account.
  2. Create a new Worker under Workers & Pages.
  3. Paste code from projects such as Cloudflare-VLESS or edgetunnel from GitHub.
  4. Set environment variables such as UUID and HOST.
  5. After deployment, import the VLESS link or QR code into v2rayNG or sing-box.

2.2 Oracle Cloud Always Free

  1. Sign up for Oracle Cloud Free Tier.
  2. Create an Instance with Ubuntu 22.04/24.04.
  3. Open required ports such as UDP 51820 or TCP 443 in the Security List.
  4. Connect via SSH and run one of the methods in Section 3.

3) Personal Server with Automated Scripts

3.1 Single-file WireGuard:

curl -sSL https://raw.githubusercontent.com/pradeeparul2/simple-wireguard-setup/main/wireguard-install.sh | sudo bash

Download the client config:

curl -o client-config.zip http://<SERVER_IP>/client-config.zip

3.2 TunnelBypass (multi-protocol):

curl -fsSL https://raw.githubusercontent.com/abdelrahman30x/TunnelBypass/main/scripts/install.sh | bash

Then run tunnelbypass and choose a protocol such as vless+reality.

3.3 Docker stack (AmneziaWG + Xray):

git clone https://github.com/seb0ch/vpn.git && cd vpn
sudo ./docker-install.sh
sudo ./deploy.sh

4) Xray VLESS + REALITY (Strongest Anti-Censorship)

apt install git
git clone https://github.com/0xevn/xray-reality-setup.git
cd xray-reality-setup
chmod +x xray-setup.sh
sh xray-setup.sh

At the end you receive a vless:// link and QR code. Import it into v2rayNG, Nekoray, or sing-box.

5) Sales and User Management System

  • VPanel: management and sales panel supporting Marzban and X-UI — github.com/lkacom/vpanel
  • VPNMarket: panel + Telegram bot + Android app — github.com/IranEclips/VPNMarket
  • Hiddify Manager: multi-user panel with 20+ protocols — github.com/hiddify/Hiddify-Manager
  • Marzban: dedicated Xray panel — github.com/Gozargah/Marzban

Install VPNMarket:

Install Hiddify Manager:
