## 📖 درباره پروژه | About the Project

این مخزن شامل یک راهنمای **تک‌فایل HTML** و کاملاً **چندزبانه** است که به شما کمک می‌کند:

- 🔧 یک **فیلترشکن خصوصی (VPN)** راه‌اندازی کنید.
- 💰 سیستم **فروش و مدیریت کاربران** بسازید.
- 🐘 پنل‌های مدیریت VPN مبتنی بر **PHP** را نصب کنید.
- 🐍 پنل‌های مدیریت VPN مبتنی بر **Python** را نصب کنید.
- 🆓 از روش‌های **کاملاً رایگان** (Cloudflare Workers، Oracle Cloud) استفاده کنید.
- 🛡️ با پروتکل‌های مقاوم در برابر فیلترینگ مثل **Xray VLESS + REALITY** آشنا شوید.

> ⚠️ **سلب مسئولیت:** این پروژه صرفاً برای اهداف آموزشی است. مسئولیت استفاده قانونی و رعایت قوانین محلی بر عهده کاربر است.

## 🗂️ محتوای راهنما | Guide Contents

### بخش ۱: روش‌های رایگان
- Cloudflare Workers (VLESS over WebSocket)
- Oracle Cloud Always Free Tier

### بخش ۲: پنل‌های PHP
- **VPNMarket** — لاراول + فیلامنت (مناسب فروش)
- **AmneziaVPN PHP Panel** — مدیریت WireGuard با Docker
- **OpenVPN Web Panel Manager** — چندپروتکلی با API کامل

### بخش ۳: پنل‌های Python
- **Marzban** — پنل حرفه‌ای Xray
- **Hiddify Manager** — بیش از ۲۰ پروتکل
- **RVG** — گیت‌وی سبک با FastAPI
- **v2pi** — گیت‌وی Xray برای شبکه محلی

### بخش ۴: پروتکل‌های مقاوم
- Xray VLESS + REALITY
- WireGuard / AmneziaWG
- Hysteria, Trojan, Shadowsocks

### بخش ۵: سیستم فروش
- ربات‌های تلگرام فروش
- پنل‌های مدیریت نمایندگی (Reseller)
- درگاه پرداخت و اتصال به BotFather
